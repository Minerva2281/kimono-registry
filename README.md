# Kimono Registry

**着物の来歴を誰でも検証できる、オープンな証明様式。** 様式(スキーマ)とコードはすべて公開。検証は無料。着物はその最初の実装。

## これは何か

眠っている着物には、履歴書(整えた記録)がありません。このプロジェクトは、
一枚の着物について「整えた履歴書」を分散ストレージ(Arweave)に保存し、
その指紋(SHA-256ハッシュ)と届け出日付だけを Solana に刻みます。

- **持ち主から預かるもの**: 写真数枚、寸法などの事実、専門家の見立て、持ち主の語りの要約
- **チェーンに刻むもの**: ハッシュと日付だけ(査定額は一切含みません)
- **誰でも見られるもの**: 戸籍ページ(写真・履歴書・チェーン上の記録へのリンク)
- **誰でも検証できるもの**: 履歴書の内容から再計算したハッシュと、チェーン上のハッシュが一致するか

このプロジェクトは「価値を査定するサービス」ではなく、「来歴を証明するインフラ」です。
着物はその最初の実装であり、様式そのものは他の文化資産(工芸品・骨董・家族の記録)にも使えるように設計しています。

## 設計上の三つの一線

1. **手数料ゼロ** — チェーンへの記録・検証に、閲覧者や持ち主への課金は一切ない
2. **査定しない** — チェーンに値段は刻まない。寸法・見立て・語りの要約・日付のみ
3. **急がせない** — このツールは、誰にも「今すぐ手放す」ことを勧めない

## 技術構成

| 要素 | 使用技術 |
|---|---|
| 記録の保存 | [Arweave](https://arweave.org/)(Irys経由でSOL払い) |
| チェーンへの記録 | [Solana](https://solana.com/) — Memo Program(専用口座を作らないため、預け金(レント)は不要) |
| クライアント | [`@solana/kit`](https://github.com/anza-xyz/kit) |

## リポジトリ構成

```
kimono-registry/
├── schema/          # 戸籍の様式(公開文書) — 載せる項目・載せない項目
├── scripts/         # 保存・記録・検証のスクリプト
├── site/            # 誰でも見られる戸籍ページ・検証ページ
└── data/            # 実際の履歴書データ(第一号など。個人情報を含むため取り扱い注意)
```

## セットアップ(開発者向け)

```bash
npm install
```

devnetで練習する場合:

```bash
npm run devnet:new-keypair   # 練習用の鍵を新規作成(価値ゼロ、何度でも作り直せます)
npm run devnet:airdrop       # 無料のテスト用SOLを取得
npm run devnet:send-memo     # devnetにテスト記録を刻む
```
