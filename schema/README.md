# 戸籍の様式(Chronicle Schema)

これは「文化資産の来歴記録」のための、オープンな様式です。着物はその最初の実装ですが、
様式そのものは工芸品・骨董・家族の記録など、他の文化資産にも使えるように設計しています。

ライセンス: [CC0](https://creativecommons.org/publicdomain/zero/1.0/) — 誰でも自由に複製・改変・実装できます。

## 設計方針

この様式は「値段をつけるための様式」ではなく、「事実・見立て・語りを、区別したまま残すための様式」です。
**測れる事実**と、**専門家の見立て(意見)**と、**持ち主の語り(記憶)**を、はっきり分けて記録します。
どれも「値段」ではありません。

## 載せる項目

| 項目 | 内容 | 性質 |
|---|---|---|
| `measurements` | 寸法(身丈・裄・袖丈など) | 測れる事実 |
| `classification` | 種類・格(振袖・訪問着 等の分類) | 専門家の見立て |
| `era_estimate` | 年代の推定 | 専門家の見立て(推定であることを明記) |
| `owner_narrative_summary` | 持ち主の語りの要約 | 記憶の記録 |
| `filing_date` | 戸籍への届け出日付 | 事実 |
| `photos` | 写真(分散ストレージへのリンク) | 記録 |

## 載せない項目

| 載せないもの | 理由 |
|---|---|
| 値踏み・査定額 | このプロジェクトは査定サービスではない。値段は「急がせる」圧力を生む |
| 証紙のない産地・作家の断定 | 確認できない情報を断定すると、来歴の記録としての信頼性を損なう |

## データ構造

機械可読なJSON Schemaを [`chronicle.schema.json`](./chronicle.schema.json) に置いています。

## チェーンに刻む情報(最小限)

Solana上に記録するのは、以下の2つだけです。それ以外の情報(写真・履歴書本文)は
分散ストレージ側にあり、チェーンには一切含みません。

```json
{
  "schema": "kimono-registry-v1",
  "sha256": "<履歴書全体のハッシュ値>",
  "filing_date": "2026-09-23"
}
```
